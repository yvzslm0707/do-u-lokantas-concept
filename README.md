# Doğuş Lokantası Concept

Create a premium, modern and elegant Turkish restaurant website for a concept project named "Doğuş Lokantası", located in Sivas, Türkiye.

DESIGN:

- Deep burgundy as the primary color.

- Dark charcoal and warm beige accents.

- Elegant typography.

- Premium restaurant atmosphere.

- Beautiful food photography.

- Smooth animations.

- Clean and luxurious layout.

SECTIONS:

1. Navigation bar and logo.

2. Full-screen hero section.

3. About section.

4. Featured dishes.

5. Food gallery.

6. Restaurant atmosphere.

7. Contact and location.

8. Footer.

REQUIREMENTS:

- Fully responsive.

- Mobile and desktop compatible.

- Turkish language.

- Smooth scrolling.

- Functional navigation.

IMPORTANT:

Do not invent restaurant history, menu items, prices, phone numbers or opening hours. Use placeholders for unverified information.
